# ConstellationManagement
Analysis and Optimization of Mega-constellation spare management strategy.

Markov Chain is used for analysis and the Genetic Algorithm is employed for the optimization with the analysis method.

## Directory Description
* BasicTest: contains scripts for the validation of general functions.
* DirectResupply: contains analysis & validation, and optimization scripts for the direct resupply
* IndirectResupply: contains analysis & validation, and optimization scripts for the indirect resupply
* HybridResupply: contains analysis & validation, and optimization scripts for the hybrid resupply
* AsymResupply: contains analysis & validation, and optimization scripts for the indirect/hybrid resupply under asymmetric constellation structure
* OnlineResuppy: contains generalized spare planning optimization using integer-programming
* Paper: contains the exact scripts used for the paper preparation

## Dependencies
Statistics and Machine Learning Toolbox™ is needed for some basic validation scripts.

The main scripts do not require the toolbox.
